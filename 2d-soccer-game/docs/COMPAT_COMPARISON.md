默认噪声 20 场均出现 >1e-12 差异，最大 0.0246225（种子 13）；全部场次进球、射门、首次触球一致。此项是指标一致，不能写成默认噪声轨迹等价。列单位不同，最大值只是逐元素误差上界，不能把它统一称为米。每场细项在 attempt-02/match-*.json；完整轨迹 SHA-256 在 COMPAT_RECEIPT.json。

受阻比例定义：有非零平移请求而本拍最终位置位移 ≤1e-10 的机器人采样数 / 有非零平移请求的采样数。速度限幅不算完全受阻。越场内边界和越外缓冲边界分开；圆盘半径计入边界。所有 600 s 轨迹有限。
