# AI 辅助声明

本迁移分支由 OpenAI Codex 代理根据小组任务生成和调试。会话系统将代理标识为 GPT-6 系列；本运行接口未提供可核验的更细模型版本或快照编号，故不猜测具体后缀。

AI 参与范围：迁移代码、脚本建模、测试与故障注入、运行记录整理、中文开发手册和示例。`reference/projectA` 为原始项目 A 的逐字快照；继承的 `robot-soccer-starter` 属于原仓库参考代码，其原作者和版权说明保留。课程 PDF 与参数提取报告为给定输入，不能记为本次 AI 创作。

所有 PASS 应有 evidence 下实际日志；未运行或缺少依赖的内容标为 NOT_RUN 或 BLOCKED。AI 产生了代码不代表课程模型验证已完成，也不能代替组员理解、导师批准和实机验证。

建议小组在提交时逐人记录：阅读和修改了哪些文件、亲手复现了哪些实验、如何审阅 AI 输出、最终承担了哪些设计责任。具体声明格式和可用范围由课程规定与导师确认。V1 增量的项目授权记录见本页末段。

M2新增的ROS标准消息代理、Simulink外层生成脚本、Webots场景派生脚本、只读定位/运动执行层、测试和手册由本次Codex会话生成并在本机运行。已有Cyberbotics motion为原文件复制，不是AI生成；SOURCES.json保存来源和哈希。模型与渲染结果是Webots V5，不是NAO6实测。

另有独立子代理从手册入口开展干净 clone 与手工 API/CLI/Webots 复现，后续接续保留原始暂停、失败和成功回执；并对最终审计做只读复核。这些仍是 AI 辅助验证，不是组员亲手 GUI 操作或人工代码审查的替代。GUI 拖拽没有自动执行，课程声明应如实区分。

冻结基线之后新增的实时二维动画、独立 MATLAB 启动器、桌面入口、动画测试和中文操作章节同样由本次 Codex 会话及协作子代理生成与审阅。启动器使用替身程序完成了参数、环境与失败路径检查，并做了变异验证；这与真实 MATLAB 图形运行是不同证据层级。真实 MATLAB 在独占图形显示上的渲染、轨迹、暂停、重开和关窗结果见 `evidence/animation/display-02/`；画面来自实际仿真帧，未使用图像生成。AI 生成的动态展示不构成 NAO6 实机或接触动力学验证，组员仍需记录自己的阅读、复现与修改工作。
