# Team 7 机器人足球 / Team 7 Robot Soccer

## 二维足球仿真 / 2D football simulation

本分支的主项目是用 MATLAB、Simulink 和 Stateflow 搭建的 4 对 4 足球仿真。进入 `2d-soccer-game/`，在 MATLAB 中运行 `start_2d.m` 即可观看默认比赛。项目说明还介绍了如何运行前锋恢复追球权的实验，以及如何复现比赛结果。

The main project on this branch is a 4v4 football simulation built with MATLAB, Simulink and Stateflow. Open `2d-soccer-game/` in MATLAB and run `start_2d.m` to watch the default match. The project guide also explains how to run the striker handback experiment and reproduce the match results.
